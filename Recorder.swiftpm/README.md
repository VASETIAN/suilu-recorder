# 畅游 1.4.3

个人拍摄与浏览工具：视频与声音、普通照片、Live Photo、内置图库、拍摄位置、前台黑屏和前台浏览录像。最低 iOS / iPadOS 16。1.4.0 改名畅游并使用石墨黑／灰白几何图标，沿用 `com.tians.recorder`，用同一 Apple 账号覆盖升级保留原应用数据；不要删除旧 App。

## iPad 导入

1. 将 `Recorder-1.4.3.swiftpm.zip` 保存到「文件」，解压。
2. 在 Swift Playgrounds 浏览并打开整个 `Recorder.swiftpm`，点击运行。首次进入相机界面，以后记住设置中的界面形态；Xcode 静态预览保留手动入口。
3. 按提示允许相机、需要声音时允许麦克风、需要拍摄位置时允许定位。系统照片权限在主动导出或开启自动导出时请求。
4. 在设置「关于畅游」确认版本 1.4.3。

1.3.0 增加默认关闭的「返回 App 后恢复录像」、点击对焦、可选操作震动、设备高负载保护，以及日期筛选、多选导出、原件与拍摄信息一起共享。缩略图与时长读取异步进行，系统照片导出独立排队；本地保存完成后即可准备下一次拍摄。相机运行错误仍保留可复制的系统错误代码。1.3.0 按使用反馈取消上下滑动曝光和手动锁定，保留点击对焦与黄色对焦框。

保留旧工程及其图库。如果 Playgrounds 为新工程分配了不同数据目录，旧工程文件不会跨目录迁移，请先从旧工程导出。

## 边浏览边录像

底部「视频」默认打开 [抖音官方网页](https://www.douyin.com/)，顶部搜索框继续用于搜索或输入网址，不再用底栏重复聚焦搜索。网页使用系统 WebKit 的移动页面设置，视频需手动播放；登录、播放能力及页面是否要求打开客户端由抖音网页决定，不等于抖音原生 App。

设置「界面形态」选择「浏览模式」，或点击相机顶栏的浏览按钮。默认打开 [小黑盒官方社区网页](https://www.xiaoheihe.cn/app/bbs/home)，可浏览网页提供的帖子；搜索框用于全网搜索，也可输入 http／https 网址。没有标签页、隐身模式或第三方 App 的原生界面接入。系统 WebKit 请求移动页面，网站实际布局和登录功能由该网站提供，不能保证与小黑盒 iPhone App 相同。

浏览主页不放录像按钮、计时、相机参数或空间信息。点击底部设置 → “边浏览边录像” → “开始录像并返回浏览”，先应用选择的录像参数，等系统确认开始后回到帖子页。需要停止时再打开设置 → “停止录像并保存”。录制中设置始终可以打开和关闭，参数调整仍需等录像停止。设置可打开相机界面，正常相机模式保留原拍摄按钮。

同一段视频可以在相机与浏览界面间切换，切换不重建视频会话；从照片切到浏览时先改为录像输出。浏览模式不自动黑屏。网页处理故障与相机错误分开显示，不将网页失败当作录像成功。启动等待在报错、进入后台或关闭设置时取消；已经被相机接受的开始操作需用停止按钮结束。

小黑盒公开社区没有手机 viewport 声明，按设备宽度布局，去除桌面顶栏和侧栏，帖子与详情为单列，分类横向滑动。1.4.3 同时移除旧网页固定在顶部的 146px 背景遮罩和列表粘连遮罩，修正分隔线超出屏幕的问题；顶部不再有遮住分类与帖子的灰色空白。1.4.3 将嵌套图片改为尺寸受约束的网格：单张为 4:3 缩略图，多张为方形缩略图，长图使用等比裁切，不再撑成长条或互相叠加；点击进入网站提供的详情。浏览界面为浅色，紧凑搜索栏和底部社区／视频／设置；返回、前进、刷新在顶栏省略号菜单中，外部网页显示域名。

适配基于当前公开页面结构，网站改版可能需要更新这些布局规则，不调用私有接口或复制其原生客户端。构建会用生产适配脚本在 macOS WebKit 中重放故障样式，检查不同宽度、分类可点与滚动；它不等于 iPhone 真机测试。

系统绿点属于 iOS 的相机使用指示，普通 App 不能覆盖、移走或局部调暗。系统亮度接口只控制整个屏幕；在刘海旁绘制黑色 App 背景不会盖住系统指示。本版保留系统显示，不增加绿点遮挡操作。

网页视频需手动播放，离开浏览界面或活动前台会暂停网页媒体。网页不能取得 App 的相机／麦克风权限，也不能通过自定义链接自动跳到另一个 App。网页媒体仍可能被系统音频规则限制或中断拍摄。仅支持 App 内浏览：返回主屏幕、锁屏或打开其他 App 后，沿用停止保存／可选分段恢复规则，没有授予额外后台相机权限。

## 任务切换器隐私

设置「隐私 → 任务切换器中隐藏内容」默认开启。App 离开活动前台时，在当前窗口上同步放置深色模糊遮罩，覆盖相机、网页、设置和图库；重新成为活动前台时移除遮罩。遮罩不拦截正常前台截图，也不隐藏系统隐私指示。这个实现要在手机的任务切换器中实际核对，源码检查和编译无法证明每个系统窗口或截取时序都已被真机验证。

## 拍摄与界面

- 相机模式底部切换录像／拍照；右上角为浏览入口、双摄／LIVE、补光和设置。相册在左下角。控制中心快捷启动会回到相机形态。
- 倍率行固定高度，不显示画中画支持提示或额外的当前倍率数字。单击取景器对焦，双指缩放；0.5×／1×／2× 与设备长焦倍率按实际镜头和格式显示。iPhone 17 Pro Max 的长焦入口为 4×／8×，空闲时点击会选择真实长焦；录制中不更换物理输入，虚拟多摄可按系统能力切镜头。顶栏显示正在使用的镜头。
- 录像设置包含 720p／1080p／4K、24／30／60／120fps、SDR／HDR，组合由设备格式决定。HDR 选择 10 位 HLG BT.2020 输入和 HEVC 输出。4K120 仅在真正支持时出现；部分高速模式需主摄，因此倍率可能变化。换镜头时不支持的组合自动调整。
- 录像中双击取景器进入黑屏；设置可开启自动黑屏，以及单击／双击／长按 0.8 秒恢复。默认降亮度到系统允许的最低值，隐藏普通状态栏及 Home 指示条。恢复、停止、错误或离开活动前台时还原亮度。系统相机和麦克风隐私指示保持正常。
- 拍照／Live Photo 同样双击取景器进入黑屏。黑屏里单击拍照，长按 0.8 秒恢复；VoiceOver 提供独立拍照和恢复操作。照片保存后保留黑屏，出现错误或离开前台时恢复。
- 双摄开关默认关闭，位于录像页右上角和设置「录像」。开启后后置主摄为大画面、前置为左上角小画面，合成一个视频；提供设备支持的 720p／1080p、24／30fps、SDR。资源预算不足会调整格式，仍不可用时恢复单摄并提示。单摄继续支持设备实际可用的 4K／120fps／HDR；拍照与 Live Photo 使用单摄。双摄过程中不切换物理镜头。

## 返回 App 后恢复录像

在设置「多任务」开启「返回 App 后恢复录像」，默认关闭。离开前台时停止并保存当前录像；回来后，等上一段保存完成、相机可用且空间足够，再沿用同一相机、画质、帧率、SDR／HDR 与麦克风设置开始新的一段。之前处于黑屏则恢复黑屏和降低亮度。新段使用当时有效的位置，详情记录接续段标识。

离开 App 的时间没有画面，文件分段保存，不拼接为连续录像。仅适用于正在录制的视频；拍照、Live Photo 不会新开录像。保存失败、低空间、相机错误、高负载停止或锁定设备会取消恢复请求；强制退出或系统终止后不会自动录像。开关关闭时，回来后由你手动开始。

## 对焦、震动与设备负载

- 单击取景器对焦，显示黄色对焦框。曝光使用苹果原生自动测光，不提供滑动曝光调节或手动 AE／AF 锁定；双指缩放、双击黑屏沿用原操作。VoiceOver 提供对焦操作。
- 「操作震动」默认开启，设备具备相应硬件时，在实际开始、接受停止、本地保存成功时给出不同反馈，可关闭。
- 「高负载保护」默认开启，读取系统温度状态与相机压力。偏高时提示；达到严重限制时停止并保存，关闭补光，冷却后恢复取景，不自动开始录像。应用不会静默改变选择的帧率或 SDR／HDR，系统仍可施加硬件限制。

## 苹果原生处理与快捷启动

照片使用 AVFoundation 的质量优先处理、自动对焦／曝光／白平衡、支持时的内容感知畸变校正和最大可直接交付照片尺寸。JPEG 原始数据完整保存，仅另生成图库缩略图。单摄视频使用苹果原生捕获、硬件编码和支持时的防抖，不加入自制美颜、AI 增强或再次压缩。双摄使用 AVCaptureMultiCamSession 获取前后画面，App 用 Core Image 合成并由 AVAssetWriter 编码为 H.264／AAC SDR 视频；这是本 App 的合成布局，不保证与苹果相机 Dual Capture 的处理、画质或规格一致。

系统按设备和拍摄条件决定融合、降噪等处理；苹果相机 App 的全部私有策略并未开放，不能保证夜景、24MP 延迟照片、超高分辨率或 8× 成片与原生相机完全相同。

安装版附带 iOS 18+ 的原生控制中心扩展：先打开畅游一次，然后控制中心 → 长按空白区域 → 添加控制 → 搜索「畅游」→ 添加「畅游相机」。点击会进入拍摄界面。系统不允许 App 自动放置控制，位置需要本人选择。

Swift Playgrounds 工程可以运行相机，但不包含扩展目标；控制中心扩展在原生 IPA 和完整构建源码包中。另提供「开启畅游相机」App Shortcut，可用于快捷指令或操作按钮。

## 图库、定位与保存

所有新内容先保存内置图库：普通照片 JPEG、视频 MOV，Live Photo 保留配对照片和动态片段。相册中可回放、查看拍摄信息，按类型／日期筛选，多选导出系统照片，或共享「原件＋拍摄信息」。共享包含未再压缩的原件和 JSON 信息文件；Live Photo 同时包含配对照片和视频。日期／时间、镜头、倍率、曝光补偿、锁定状态、位置和接续段标识随信息文件导出。导出保留 App 原件。只在你确认删除后才删除图库内容。设置可开启「拍摄后自动导出系统照片」，默认关闭；系统照片导出独立排队，失败保留本地原件并显示可重试状态。共享用临时副本，在关闭分享窗口后清理；异常退出时下次打开只清理本应用的分享临时目录。

拍摄写暂存目录，完整写入后在同一存储卷移动到图库，不留下重复暂存副本。保存失败保留原文件，重启尝试恢复。剩余空间低于设置阈值会停止并保存。

位置需使用期间授权，拍摄使用最近 60 秒的有效位置。定位不可用仍能拍摄。详情包含时间、镜头、分辨率、帧率、SDR／HDR、声音、大小、经纬度、精度及有效海拔；照片写 GPS，电影写 QuickTime ISO 6709，导出系统照片时附带资产位置。旧版未知动态范围不推断成 HDR。

## 返回主屏幕的限制

1.4.3 移除无法在当前个人录像环境可靠工作的画中画实现、入口和背景音频声明。返回主屏幕、打开其他 App 或锁屏会停止并保存；回到前台可以手动重新开始，或使用默认关闭的分段恢复开关。双摄同样遵守这些规则。

本工程不注册或模拟通话，不覆盖系统隐私指示，不授予后台相机权限。网页浏览和视频播放发生在本 App 内，网页音频仍可能被系统限制或中断录制。

## iPhone 构建与安装

仓库的 GitHub Actions 使用 Xcode 26.3、真实 iPhoneOS SDK 编译全部源码、图标和 App Intents，输出 arm64 未签名 IPA。Windows 使用自己的免费 Apple 账号通过官方 iLoader 签名安装；密码和验证码由本人在工具中输入。免费签名通常需每 7 天刷新，使用同一账号和应用标识覆盖安装。

完整 SDK 构建证明代码能编译；实际取景器、录音、HDR／120fps 成片及系统中断仍需手机验证，不能把能力选项或编译成功当作真机测试。
