# 随心记 2.4.1

个人拍摄工具：视频与声音、普通照片、Live Photo、内置图库、拍摄位置、前台黑屏。最低 iOS / iPadOS 16。新名称和书本图标沿用 `com.tians.recorder`，用同一 Apple 账号覆盖升级即可保留原应用数据；不要删除旧 App。

## iPad 导入

1. 将 `Recorder-2.4.1.swiftpm.zip` 保存到「文件」，解压。
2. 在 Swift Playgrounds 浏览并打开整个 `Recorder.swiftpm`，点击运行。运行的 App 直接进入录像界面；Xcode 静态预览保留手动入口。
3. 按提示允许相机、需要声音时允许麦克风、需要拍摄位置时允许定位。向系统照片添加权限仅在主动导出时请求。
4. 在设置「关于随心记」确认版本 2.4.1。

2.4.1 修正前台恢复时重复启动／配置相机会话的时序，等待系统中断结束后恢复。相机运行错误会保留域、代码和底层错误，可在设置「最近相机错误」复制；SDR／HDR 和原有画质选项继续保留。此修改已通过生命周期回放，真实手机打开与返回后的行为仍需验证。

保留旧工程及其图库。如果 Playgrounds 为新工程分配了不同数据目录，旧工程文件不会跨目录迁移，请先从旧工程导出。

## 拍摄与界面

- 默认进入录像。底部切换录像／拍照；右上角同一位置为画中画／LIVE，旁边是补光和设置。相册在左下角。
- 倍率行固定高度，不显示画中画支持提示或额外的当前倍率数字。单击取景器对焦，双指缩放；0.5×／1×／2× 与设备长焦倍率按实际镜头和格式显示。iPhone 17 Pro Max 的长焦入口为 4×／8×，空闲时点击会选择真实长焦；录制中不更换物理输入，虚拟多摄可按系统能力切镜头。顶栏显示正在使用的镜头。
- 录像设置包含 720p／1080p／4K、24／30／60／120fps、SDR／HDR，组合由设备格式决定。HDR 选择 10 位 HLG BT.2020 输入和 HEVC 输出。4K120 仅在真正支持时出现；部分高速模式需主摄，因此倍率可能变化。换镜头时不支持的组合自动调整。
- 录像中双击取景器进入黑屏；设置可开启自动黑屏，以及单击／双击／长按 0.8 秒恢复。默认降亮度到系统允许的最低值，隐藏普通状态栏及 Home 指示条。恢复、停止、错误或离开活动前台时还原亮度。系统相机和麦克风隐私指示保持正常。
- 拍照／Live Photo 同样双击取景器进入黑屏。黑屏里单击拍照，长按 0.8 秒恢复；VoiceOver 提供独立拍照和恢复操作。照片保存后保留黑屏，出现错误或离开前台时恢复。
- 同一个相机预览层在主界面和受支持的画中画之间移动，避免预先绑定额外的屏幕外预览。画中画偏好为紧凑横向尺寸；最终窗口大小及缩放仍由系统决定。

## 苹果原生处理与快捷启动

照片使用 AVFoundation 的质量优先处理、自动对焦／曝光／白平衡、支持时的内容感知畸变校正和最大可直接交付照片尺寸。JPEG 原始数据完整保存，仅另生成图库缩略图。视频使用苹果原生捕获、硬件编码和支持时的防抖，不加入自制美颜、AI 增强或再次压缩。

系统按设备和拍摄条件决定融合、降噪等处理；苹果相机 App 的全部私有策略并未开放，不能保证夜景、24MP 延迟照片、超高分辨率或 8× 成片与原生相机完全相同。

安装版附带 iOS 18+ 的原生控制中心扩展：先打开随心记一次，然后控制中心 → 长按空白区域 → 添加控制 → 搜索「随心记」→ 添加「随心记相机」。点击会进入拍摄界面。系统不允许 App 自动放置控制，位置需要本人选择。

Swift Playgrounds 工程可以运行相机，但不包含扩展目标；控制中心扩展在原生 IPA 和完整构建源码包中。另提供「开启随心记相机」App Shortcut，可用于快捷指令或操作按钮。

## 图库、定位与保存

所有新内容先保存内置图库：普通照片 JPEG、视频 MOV，Live Photo 保留配对照片和动态片段。相册中可回放、查看拍摄信息、导出系统照片或共享原文件；导出保留 App 原件。只在你确认删除后才删除图库内容。

拍摄写暂存目录，完整写入后在同一存储卷移动到图库，不留下重复暂存副本。保存失败保留原文件，重启尝试恢复。剩余空间低于设置阈值会停止并保存。

位置需使用期间授权，拍摄使用最近 60 秒的有效位置。定位不可用仍能拍摄。详情包含时间、镜头、分辨率、帧率、SDR／HDR、声音、大小、经纬度、精度及有效海拔；照片写 GPS，电影写 QuickTime ISO 6709，导出系统照片时附带资产位置。旧版未知动态范围不推断成 HDR。

## 画中画与返回主屏幕的限制

只有系统报告支持并启用了多任务相机、运行环境声明背景音频且 AVKit 判断可以开启时，正在进行的录像才能进入正常可见画中画。小窗保留实时画面与 REC。关闭、收起、锁屏或相机中断时停止并保存，返回前台可以重新开始一段。

**普通 iPhone 个人录像 App 不具备后台相机权限。** 苹果文档列出的许可条件包括特定 iPad 环境，或符合条件的真实 VoIP 应用／受限多任务相机授权。本工程没有注册或模拟通话，不添加 VoIP 或隐藏窗口；不支持时按钮禁用，返回主屏幕停止并保存。改窗口大小、升级名称或重新签名不能授予该权限。

## iPhone 构建与安装

仓库的 GitHub Actions 使用 Xcode 26.3、真实 iPhoneOS SDK 编译全部源码、图标和 App Intents，输出 arm64 未签名 IPA。Windows 使用自己的免费 Apple 账号通过官方 iLoader 签名安装；密码和验证码由本人在工具中输入。免费签名通常需每 7 天刷新，使用同一账号和应用标识覆盖安装。

完整 SDK 构建证明代码能编译；实际取景器、录音、HDR／120fps 成片及系统中断仍需手机验证，不能把能力选项或编译成功当作真机测试。
